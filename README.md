# SpotFolk — spotfolk.eu

The community map of [SpotFolk](https://spotfolk.eu), born from the map of photographer Fabio Costantini.

spotfolk.eu runs **the same code as [fabiocostaph.com](https://fabiocostaph.com)** (repo `fabio-costa-ph`):
on this domain the site shows only SpotFolk (map, passport, sign-up), with its own look.
Accounts are the same on both sites.

Don't edit the site files here: change them in `fabio-costa-ph`. The workflow *Sync from fabiocostaph.com*
copies them here every 30 minutes (or run it by hand from the Actions tab). Files that belong only to this repo:
`CNAME`, `README.md`, `robots.txt`, `sync.sh`, `.github/`.
